Portable skills, local trust

Agent workflows are becoming shareable packages. The useful engineering move is to standardize the format while keeping authority, credentials, and verification in your own hands.

1. Package the procedure, not the permission

A useful skill is a small folder that gives an agent procedural knowledge: instructions, scripts, references, and an expected output shape. That is different from granting access. Keep secrets, deployment credentials, production destinations, and approval rules outside the skill so the same workflow can travel between agents without carrying your trust boundary with it.

Why this matters
Portability lets you reuse expertise without accidentally turning a shared instruction file into a shared authority file.

2. Make every skill observable at the edges

Give a skill explicit inputs, outputs, side effects, and failure modes. A code-review skill should say which files it may inspect, what it may write, and what evidence it must return. A release skill should stop at a reviewable plan unless the caller supplies an explicit approval. This makes skills composable: an orchestrator can route work between them without guessing what “done” means.

Why this matters
Clear boundaries turn a skill from prompt folklore into a testable software component.

3. Test the same skill in more than one runtime

Anthropic says Agent Skills has been integrated by more than 70 agent platforms, including ChatGPT, Cursor, GitHub Copilot, and VS Code. Treat that as a reason to write compatibility tests, not as proof that behavior is identical everywhere. Run a small conformance suite across the runtimes you actually support: discovery, file loading, script execution, expected artifacts, and refusal when a required input is missing.

Why this matters
A shared format reduces lock-in only if the behavior you depend on survives the move between hosts.

4. Review skills like dependencies

Read a skill’s scripts and references before installing it; pin revisions; record provenance; and scan for instructions that try to expand scope, exfiltrate data, or bypass review. Independent analysis of the growing skills ecosystem warns that a neutral home and a common format do not themselves establish safety or interoperability. Your repository should maintain an allowlist and a lightweight review record for skills that can touch source code, networks, or customer data.

Why this matters
Reusable agent knowledge is also reusable attack surface, so the supply-chain habits from packages belong here too.
Tool spotlight · meaningfully updated standard

Agent Skills moves to the Agentic AI Foundation

What it does: Agent Skills is an open format for packaging specialized agent knowledge and workflows in a folder, typically centered on a SKILL.md file with supporting scripts and references. On October 22, Anthropic donated the standard, its name and logo, GitHub organization, and agentskills.io domain to the Linux Foundation’s Agentic AI Foundation.

Why it was built: Anthropic says Claude Code needed procedural knowledge that general model training did not provide. A shared, vendor-neutral format lets developers publish a workflow once and make it discoverable across compatible agents, while community governance can shape versioning, proposals, and security guidance.

How to use it: Start with one repeatable task in your repository—such as running a release checklist or preparing a bug report. Create a narrow skill with a clear trigger, numbered procedure, safe scripts, required inputs, and a verification section. Test it in your main agent and one other compatible runtime, then pin the reviewed revision. Keep credentials and irreversible actions outside the folder, and require a human approval step for production changes.

One thing to try before lunch

Convert one page of your team’s internal runbook into a skill. Add three tests: it produces the expected artifact, it refuses when a required input is absent, and it stops before an irreversible action. Run the skill twice with two agents and compare the evidence, not just the final prose.
